# 17. CyberChef - Hoperation Save McSkidy

## Solution:

- This challenge we are meant to save McSkidy from a fortress by cracking some locks using CyberChef.
- For level 1:
   - First we use the inspect tab to check what the logic is for the password and username.
   - We get to know that the username is the name of the gaurd in base-64.
   - Also, if we ask the gaurd for the password in base064, it will give it to us, converting it to normal text, we crack the outer wall.

- For level 2:
   - We use the same inspect tab method again, the username is once again gaurd name in base-64.
   - We ask 'did you change the password' in base64 to get the password which on which we use b-64 decoding twice to get the password and crack the second level.

- For level 3:
   - The username follows the same logic again.
   - We ask the gaurd 'password please` and get the password in b-64 decode from b-64 and xor using the key cyberchef.

- For level 4:
   - Username follows same logic.
   - We ask the gaurd 'password please` and get the password in b-64 and get an md5 hash and then decode that.

- For level 5:
   - Username follows same logic.
   -  We ask the gaurd 'password please` and get the password in b-64 and we get a case R2 which we can see in the inspect tab and so we follow those instructions.
   -  So, we convert from base-64, from hex, and then reverse it.
   -  This helps us crack the final level and help save McSkiddy.
