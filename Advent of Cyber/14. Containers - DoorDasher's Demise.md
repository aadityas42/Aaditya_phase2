# 14. Containers - DoorDasher's Demise

## Solution:

- This challenge is related to docker.
- We first use `docker ps` to check which services are running.
- We checkout a web application and check uptime using `docker exec -it uptime-checker sh` .
- Next, we try to access the deployer container `docker exec -it deployer bash`
- Exploring this container gives us the flag.
- `sudo /recovery_script.sh` runs the script and we can find the flag in the same directory as it which we can read using `cat`

## Flag:
```
THM{DOCKER_ESCAPE_SUCCESS}
```
