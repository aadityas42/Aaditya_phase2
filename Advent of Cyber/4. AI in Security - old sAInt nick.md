# 4. AI in Security - old sAInt nick.md

## Solution:

- The first part in this challenge is a red team or the attacking part, where we use an AI to generate a script and exploit a weakness using it.
- We save the script we get using nano and then run it, which gives us the second flag.

- The next part in analysing the attack logs, as the blue team or defensive side.
- The AI analyses and gives us the IP of source of attack, time and date, url and username used and also recognises that it was an SQL injection.

- Finally, the last part is to analyse the source code and fix it, which AI once again tells us the mthodology for.
- On completion of these 3 parts, we get the first flag.
