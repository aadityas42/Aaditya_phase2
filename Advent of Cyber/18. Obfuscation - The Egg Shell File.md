# 18. Obfuscation - The Egg Shell File

## Solution:

- This challenge is about Obfuscation which makes data hard to read.
- First, we convert the first string from base-64 and paste it in the appropriate place in the script.
- We then run the script using powershell and get the first flag.
- For the next part we XOR a given string using the key '0x37' , convert the result to hex and paste it in the script and run it again.
- This gives us our second flag.
