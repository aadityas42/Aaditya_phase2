# 13. YARA Rules - YARA mean one!

## Solution:

- This challenge is about using YARA.
- YARA is used for malwate classification by recognizing patterns and digital footprints left behind by attackers.
- We can define YARA rules with certain parameters to find malwares that match them
- We write the following YARA rule for our case:
  
```
  rule TBFC_Simple_MZ_Detect
{
    meta:
        author = "me"
        description = "Search for messages"
        date = "2025-12-26"

    strings:
        $tbfc_message = /TBFC:[A-Za-z0-9]+/ ascii

    condition:
        $tbfc_message
}
```
we save this file with a .yar extension and run it using `yara -rs /home/ubuntu/TBFC_Simple_MZ_Detect /home/ubuntu`
