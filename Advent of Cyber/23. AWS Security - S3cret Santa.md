# 23. AWS Security - S3cret Santa

## Solution:

- This challenge is about AWS(Amazon Web Services)
- We learn a little about Identity and access management(IAM)
- We use `aws iam get-user-policy --policy-name POLICYNAME --user-name sir.carrotbane` to get the name of the policy for Sir Carrotbane's account.
- Next, we check out roles.
- We can use `aws sts assume-role --role-arn arn:aws:iam::123456789012:role/bucketmaster --role-session-name TBFC` to assume the role of Bucketmaster by giving us temporary credentials.
- Next we checkout simple storage service(S3)
- We use `aws s3api get-object --bucket easter-secrets-123145 --key cloud_password.txt cloud_password.txt` to infiltrate a bucket and print some sensitive data
