# 9. Passwords - A Cracking Christmas

## Solution:

- This challenge is about cracking passwords using password crackers like john.
- Since the pdf and zip files require a password, we use a list of possible password that is rockyou.txt, using pdfcrack and john.
- We just use the linux commands that write all of the possible passwords and brute force it, having found out how long the password is and trying to match the encrypted key.
- We did something similar in pwncollege with johntheripper.
