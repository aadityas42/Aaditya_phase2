# 16. Forensics - Registry Furensics

## Solution:

- This challenge is related to forensics using the windows registry.
- We use registry editor which is an in-built windows tool for this challenge.
- `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Enum\USBSTOR` lets us see all usb connected devices.
- `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Explorer\RunMRU.` lets us view programs run by the user.
- We follow these steps for clean loading:
  1.On the Load hives pop-up, navigate to C:\Users\Administrator\Desktop\Registry Hives
  2. Select the desired hive file (e.g., SYSTEM)
  3. Hold SHIFT, then press Open to load associated transaction log files. This ensures you get a clean, consistent hive state for analysis.
- After this, we also learn to investigate register keys.
