# 1. All Signs Align

## Solution:

- Looking at the chal.py code, we get to know that it uses euler's criterion. the function get_x() returns a quadratic residue and get_y() returns a non-residue.

- The output for each charecter of the flag is either a*quadratic residue or a*-quadratic residue

- From here, every charecter is either a residue giving 1 and non-residue giving 0, or vice-versa depending on the value of a.

- If we use all the values we are giving in the out.txt to get a string of binary and convert one of the binaries into charecters, we get our flag.

- Script used to convert the out.txt into binary is below

```
p = 9129026491768303016811207218323770273047638648509577266210613478726929333106121387323539916009107476349319902011390210650434835260358014251332047605739279

text = open("out.txt").read().strip()
nums = text[1:-1].split(",")
arr = [int(n) for n in nums]

def legendre(x):
    return 1 if pow(x, (p-1)//2, p) == 1 else 0

bits0 = "".join("0" if legendre(c) else "1" for c in arr)
bits1 = "".join("1" if legendre(c) else "0" for c in arr)

print("residue 0")
print(bits0)
print()
print("residue 1")
print(bits1)
```
