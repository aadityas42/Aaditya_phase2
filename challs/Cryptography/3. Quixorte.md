# 3. Quixorte

## Solution:

- The filename quote.png.enc tells us that it is supposed to be a png. Opening it in hxd, we can see that it's header differs from the standard png header, so presumably we need to change the hex using a menthod specified in the script.

- Since the first 8 bytes of the png file are standard and are known, we can use it to reconstruct the 8byte key.

- The encryption part works by rotating the bits to the right and then doing an XOR in a sliding manner.
 
- Now, we need to undo it by doing the sliding XOR operations in reverse order and then undoing the rotation by rotating it left.

```
def inv_rotate(b, i):
    r = i % 8
    return ((b << r) | (b >> (8 - r))) & 0xFF

def main():
    with open("quote.png.enc", "rb") as f:
        enc = bytearray(f.read())
    png_header = bytes.fromhex("89504E470D0A1A0A")

    S = []
    for i in range(8):
        r = i % 8
        R_i = ((png_header[i] >> r) | (png_header[i] << (8 - r))) & 0xFF
        S.append(enc[i] ^ R_i)

    key = bytearray(8)
    key[0] = S[0]
    for i in range(1, 8):
        key[i] = S[i] ^ S[i - 1]

    K = len(key)
    for i in range(len(enc) - K, -1, -1):
        for j in range(K - 1, -1, -1):
            enc[i + j] ^= key[j]

    for i in range(len(enc)):
        enc[i] = inv_rotate(enc[i], i)

    with open("recovered.png", "wb") as f:
        f.write(enc)
if __name__ == "__main__":
    main()
```
