## Solution:

- Looking at the chal.py code, we get to know that to obtain the flag, the hex must be converted via the method in the script, 2 bytes at a time using a key.

- We can furthur decipher that it works on 2 equations:

  c0 = k0m1 + k1m0 (mod 257) AND c1 = k0m0 + 3k1m1 (mod 257)

- We can use the plaintext hex we are given and convert it to decimal and do the same witht he first 2 pairs of 2 bytes of the flag hex to get the values of k0 and k1, which are found to be 60 and 6 respectively.

- Since we know the ciphertext c and k for the 2 equations now we must find m.

- To do this, we represent the equations in matrix form, and find the inverse of matrix m and multiply it by both sides to get the equation in terms of m, from which we get:

  m0​​​ = 174c1​ + 102c0​ (mod257) AND m1 = 34c1 ​+ 174c0 ​(mod257)​

- We then do this for all the byte pairs in the ciphertext using a script to get the flag.

```
p = 257
ct_hex = "9813d3838178abd17836f3e2e752a99d5cd3fba291205f90c1d0a78b6eca"
ct = bytes.fromhex(ct_hex)

def decrypt(c0, c1):
    m0 = (174 * c1 + 102 * c0) % p
    m1 = (34 * c1 + 174 * c0) % p
    return bytes([m0, m1])

pt_bytes = bytearray()

for i in range(0, len(ct), 2):
    c0, c1 = ct[i], ct[i+1]
    pt_bytes.extend(decrypt(c0, c1))

print(pt_bytes)
```
