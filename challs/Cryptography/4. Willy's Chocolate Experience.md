# 4. Willy's Chocolate Experience

## Solution:

- The function imagine_lab in the script is essentially return a value: S = 13^m + 37^m (mod p)

- Candybag is where all S values are stored

- Then,to recover ticket(n) value we need to solve 2 unknown variable equations to get the values of A=13^n-1 and B=37^n-1

- We have B/A=(37/13)^n-1(mod p)

- Let r = 37.13^-1 (mod p)

- k = B.A^-1 (mod p)

- Then we have r^n-1=k mod p

- This is a discrete log problem.

- I thought of approaching it using baby-step giant-step alone but it turned out to be infeasable so i pivoted to using Pohlig-Hellman which would break it down into smaller discrete log problem, and these smaller ones can be solved using bsgs.

- We use a script to run this algorithm and get our flag.

```
import math

def modinv(a, m):
    return pow(a, -1, m)

def long_to_bytes(n: int) -> bytes:
    if n == 0:
        return b"\x00"
    length = (n.bit_length() + 7) // 8
    return n.to_bytes(length, "big")

def bsgs(g, h, p, order):
    m = int(math.isqrt(order)) + 1
    #baby steps [g^0, g^1, g^2, ..., g^(m-1)]
    table = {}
    e = 1
    for j in range(m):
        table.setdefault(e, j)
        e = (e * g) % p

    #giant steps [h * g^(-m i)]
    g_inv_m = pow(g, -m, p)
    gamma = h
    for i in range(m + 1):
        if gamma in table:
            return i * m + table[gamma]
        gamma = (gamma * g_inv_m) % p

    raise ValueError("log not found")

def crt(residues, moduli):
    #Chinese Remainder Theorem for pairwise coprime moduli
    x = 0
    M = 1
    for (a, n) in zip(residues, moduli):
        k = ((x - a) * modinv(n, M)) % M
        x = a + n * k
        M *= n
    return x % M

def pohlig_hellman(g, h, p, factors):
    N = p - 1
    residues = []
    moduli = []
    for q in factors:
        n_i = N // q
        g_i = pow(g, n_i, p)
        h_i = pow(h, n_i, p)
        if h_i == 1:
            x_i = 0
        else:
            x_i = bsgs(g_i, h_i, p, q)

        residues.append(x_i)
        moduli.append(q)

    return crt(residues, moduli)

inv24 = modinv(24, p)
A = ((37 * u - v) * inv24) % p   # = 13^(n-1)
```
