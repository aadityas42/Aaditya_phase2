# 4. VeridisQuo

## Solution:

- I found out that jadx is used to analyse apks and installed it
  
- I went through the different folders in jadx and looked for anything that stood out, `byuctf.downwiththefrench` stood out. By inspecting it, we know that the flag is seperated into 28 parts and that it was erasing the flag.
  
- In the MainActivity folder the line `setContentView(R.layout.activity_main);` points towards something going on in activity_main, so i checked it out, and sure enough, the parts of the flag were present in it.
  
- These parts were scrambled, but each had a value for margin height and width.

- If we map these out, arranging them according to the values given, we can see that the flag reads out `byuctf{android_piece_0f_c4ke}`
