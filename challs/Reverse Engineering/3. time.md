# 3. time

## Solution:

- I used gdb to analyse the file

-  I used the `diassemble main` command to read what's going on in the main function
  
- We need to get the number that is randomly generated by a rand function before the program asks for input
  
- From here, I put a breakpoint after rand so that the program breaks there, giving us the value generated by the rand function
  
- Then we enter the number we just got from the rand function as our guess and are successful
