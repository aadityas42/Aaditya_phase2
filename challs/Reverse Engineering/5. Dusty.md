## Solution:

- I used gdb to disassemble the file.

- I put a breakpoint in main and then cycled through the list of functions by giving random inputs.

- The name `_ZN10shinyclean4main17h4b15dd54e331d693E` stood out since executing the file tells us the name of the challenge is shiny clean rust remover.

- I then disassembled this function using gdb and analysed the assembly code

- There is a large list of mov instructions which is indicative of a flag.
  
- Inspecting the rest of the code tells us that there is also an xor operation happening on every charecter with `0x3f` by using a loop using the `jb` instruction.

- Using XOR on all of the charecters from the mov instructions gives us our flag.
